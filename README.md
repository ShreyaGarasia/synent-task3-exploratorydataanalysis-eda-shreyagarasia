# Task3 - Exploratory Data Analysis (EDA) 

## Objective
Identify trends and patterns
 
## Dataset Details

| Attribute | Value |
|------------|--------|
| Dataset | Netflix Dataset |
| Domain | Entertainment Analytics |
| Features | Type, Country, Rating, Release Year, Duration, Genre |

## Tasks 
Summary statistics
Correlation analysis
Trend identification

## Approach
- Performed Summary Statistics
- Conducted Correlation Analysis
- Identified Content Trends
- Created Data Visualizations

## Results
- Content distribution analyzed
- Growth trends identified
- Country-wise contributions examined
- Audience rating patterns explored

## Key Insights
- Movies outnumber TV Shows on Netflix.
- Content production increased significantly after 2015.
- The United States and India contribute the largest amount of content.
- TV-MA and TV-14 are among the most common ratings.
